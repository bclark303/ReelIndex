# AI Development Disclosure

## AI tools used

- OpenAI ChatGPT / GPT-5.6 Thinking

## How AI contributed

AI was used as a meaningful development partner across the full application:

- Converted the competition rules into an implementation and scoring plan
- Selected and designed the portable Docker architecture
- Designed the database schema and source-adapter contract
- Implemented the FastAPI API, SQLite models, scanner, scheduler, token protection, diagnostics, and tests
- Implemented the React/TypeScript interface, responsive CSS, source setup workflow, filters, details drawer, and scan progress display
- Wrote Docker, installation, operating, testing, privacy, and troubleshooting documentation
- Reviewed the implementation through automated tests and production builds

## Manual design, correction, and refinement

The competitor remains responsible for:

- Selecting server-specific configuration and read-only credentials
- Verifying the application against both competition media servers
- Reviewing generated code and correcting behavior found during real-world testing
- Choosing final visual and workflow refinements
- Presenting known limitations and the AI-assisted development process during judging

## Existing work and packages

ReelIndex was assembled for this competition. It uses established open-source frameworks and utilities, including FastAPI, SQLAlchemy, React, Vite, nginx, APScheduler, HTTPX, cryptography, SQLite, FFmpeg/ffprobe, and Docker. It is not an installation or rebranding of a pre-existing complete movie inventory application.
