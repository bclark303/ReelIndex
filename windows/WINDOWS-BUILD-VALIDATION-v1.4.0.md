# ReelIndex Windows v1.4.0 Validation

## Release scope

Version 1.4.0 combines the previously proposed 1.4.0, 1.4.1, and 1.4.2 work into one unified native-container release.

Native-first deep analysis now covers:

- Matroska and WebM (existing EBML parser)
- MP4, M4V, and MOV (ISO Base Media / QuickTime atoms)
- AVI (RIFF headers and stream lists)
- ASF and WMV (ASF header objects)
- MPEG transport streams: TS, M2TS, and MTS (bounded PAT/PMT/PES packet sampling)
- MPEG program streams: MPG and MPEG (bounded pack/PES sampling)

`ffprobe` remains a bounded fallback for malformed, unusual, unsupported, or incomplete files. It is no longer the normal analysis path for the listed containers.

## Native metadata

The native parsers can extract, where the container supplies it:

- Container type
- Duration
- Video and audio codecs
- Width and height
- Resolution label
- Audio channels and language
- Frame rate
- Bit depth
- Track and subtitle counts
- Basic HDR signalling
- Estimated overall bitrate from original file size and duration
- iTunes-style embedded MP4 cover artwork

MP4-family analysis samples both the beginning and end of the file to locate a trailing `moov` atom without traversing the entire movie. MPEG transport and program streams use bounded head/tail packet samples.

## Upgrade behavior

The in-place patch preserves:

- SQLite database
- Source configurations
- Encrypted credentials
- Poster cache
- Scan history and logs
- Resumable Deep Scan queue

Existing successful deep metadata remains cached. To benchmark all new parser families against already analyzed files, use **Deep scan → All files**. To continue unfinished work, use **Resume deep**.

## Known fallback cases

`ffprobe` may still be used when:

- An MP4 `moov` atom is larger than or outside the bounded samples
- A transport stream lacks usable timing or codec headers in the sampled packets
- HEVC transport-stream dimensions cannot be derived from sampled headers
- A file is malformed, encrypted, nonstandard, or mislabeled
- Extended metadata requested by ReelIndex is absent from the native result

The source media remains read-only throughout all native and fallback analysis.
